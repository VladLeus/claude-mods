# Common Resume Scenarios

## Scenario 1: Clean Continuation

**Situation:** All changes from handoff are present, no conflicts

**Actions:**
- Verify tasks match current state
- Proceed with next steps from action items
- Apply documented learnings

## Scenario 2: Diverged Codebase

**Situation:** Some changes missing or modified since handoff

**Actions:**
- Identify what changed and why
- Adapt plan to current state
- Re-evaluate approach if significant divergence
- Consider whether to restore missing changes or work with current state

## Scenario 3: Incomplete Handoff Work

**Situation:** In-progress tasks from handoff not finished

**Actions:**
- Complete unfinished work first before proceeding
- Verify partial implementations still make sense
- Check if incomplete work blocks next steps

## Scenario 4: Stale Handoff

**Situation:** Major refactoring occurred, context significantly outdated

**Actions:**
- Re-evaluate strategy from scratch
- Determine if handoff approach still valid
- May need fresh research/planning
- Consider creating new handoff after catching up
